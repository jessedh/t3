# Contributing

Thanks for your interest in the T3 Programmable Fiat Framework. This is a
**counsel-pending technical preview / reference implementation** (see
[REGULATORY-STATUS.md](REGULATORY-STATUS.md)); contributions are welcome with that
context in mind.

## Ground rules

- **Security issues:** do not file public issues — follow [SECURITY.md](SECURITY.md).
- **Scope:** this targets a *permissioned* Besu consortium. Changes that assume a
  public/permissionless deployment, or that re-introduce removed Avalanche-era
  privacy machinery, are out of scope (see `Documentation/envelope_besu/`).
- **No secrets in commits:** never commit `.env`, private keys, or credentials.
  CI runs gitleaks; the public snapshot is generated by a default-deny allowlist.

## Development setup

Requires Node 22 (see `.nvmrc`). The smart contracts have no runtime npm
dependency; each shipped service (`indexer/`, `relayer/`, `keeper/`) has its own
`package.json`.

```bash
npm install            # root: contracts + scripts
npm run compile        # compile all facets
npm test               # full Hardhat suite
```

See the README "Local quickstart" for running the full stack against a local
Besu devnet.

## Before opening a PR

Run the same gates CI runs:

```bash
npm run compile
npm test                                   # expect 0 failing
node scripts/selector-collision-check.js   # no facet selector collisions
node scripts/check-manifest-abi-parity.js  # manifest <-> indexer ABI parity
```

If you add or change a facet, register it in `scripts/lib/facet-manifest.js`
(the single source of truth) and follow the README guidance for active facets.
If you change a storage struct, keep the layout append-only and update the
storage-layout snapshot.

## PR expectations

- Keep PRs focused; describe the "why".
- Include tests for behavior changes.
- Don't widen scope with unrelated refactors.
